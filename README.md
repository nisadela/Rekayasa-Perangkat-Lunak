# Sistem Informasi Pemesanan dan Manajemen Jasa Commision Art Berbasis Web
Website ini merupakan sistem informasi berbasis web yang dirancang untuk mempermudah proses pemesanan jasa commission art serta pengelolaan layanan secara terstruktur dan terintegrasi. Sistem ini menyediakan fasilitas bagi pelanggan untuk melihat layanan artist, melakukan pemesanan, dan memantau perkembangan pesanan. Artist dapat mengelola informasi jasa, menerima dan memproses pesanan, serta memperbarui status pengerjaan. Sementara itu, admin bertanggung jawab dalam mengelola data pengguna, data jasa, pesanan, dan pembayaran, serta memastikan seluruh aktivitas sistem berjalan dengan baik.
